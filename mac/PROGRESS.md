# LiveCaptions Translator · macOS 版开发进展

> 这份文档用大白话记录 Mac 版的进展，让你随时看懂做到哪了、怎么用、下一步做什么。
> 最后更新：字幕来源 + 翻译层已完成，界面可显示原文与译文。

---

## 一句话说清这个项目在干嘛

Windows 版的原理是：借用 Windows 系统自带的「实时字幕」功能拿到文字，再翻译。
但 **macOS 没有这个功能**，所以 Mac 版必须自己做两件事：

1. **听见电脑正在播放的声音** → 转成文字（语音识别）
2. **把文字翻译成你要的语言** → 显示出来

我们不动 Windows 的任何代码，所有 Mac 相关代码都放在独立的 `mac/` 文件夹里。

## 用到的技术（为什么选它们）

- **Avalonia**：跨平台的界面框架（相当于 Mac 上能用的 WPF 替代品），能最大程度复用 C# 代码。
- **Whisper.net**：语音转文字，本地离线运行，不上传你的声音，Apple 芯片跑得快。
- **SoundFlow / miniaudio**：负责从音频设备采集声音，底层走 macOS 原生接口，无需额外安装。

以上都是纯 C#、自带所需的原生库，不需要你再手动装别的东西（除了下面说的 BlackHole）。

## 你要怎么试用（一次性配置）

macOS 出于安全，不允许程序直接抓「系统正在播放的声音」，业界通用做法是装一个免费的
**虚拟声卡 BlackHole** 中转一下。步骤：

1. **安装 BlackHole**
   ```
   brew install --cask blackhole-2ch
   ```
2. **建一个「多输出设备」**（让声音既能听到、程序又能抓到）
   - 打开「音频 MIDI 设置」（Audio MIDI Setup）
   - 左下角 `+` → 新建「多输出设备」
   - 勾选你的「扬声器/耳机」+「BlackHole 2ch」
   - 点系统右上角音量图标，把输出切到这个「多输出设备」
3. **回到 App**
   - 点「刷新」，在设备下拉框选 **BlackHole 2ch**
   - 点「开始」（首次会自动下载约 140MB 的识别模型，请等待）
   - 播放一段英文视频，看字幕区是否出现识别文字

> 如果没成功，把界面状态栏那行提示文字发我即可。

## 代码结构（放在 `mac/` 下）

```
mac/
├── Program.cs / App.axaml        程序入口
├── Views/MainWindow              主窗口界面 + 逻辑
├── Audio/
│   └── SystemAudioCapture.cs     从设备采集音频，转成识别需要的格式
├── Captions/
│   ├── ICaptionSource.cs         「字幕来源」的统一接口（扩展点）
│   ├── WhisperModelProvider.cs   自动下载/缓存识别模型
│   └── WhisperCaptionSource.cs   核心：采集→识别→出字幕
├── Services/                     翻译相关（进行中）
├── Models/                       数据结构
└── Utils/AppPaths.cs             数据/模型存放路径
```

## 下一步计划

1. **悬浮字幕窗**：像原版一样在屏幕上浮一条字幕。
2. **设置持久化**：记住你选的设备、翻译引擎、目标语言、OpenAI 密钥等。
3. **翻译引擎设置界面**：填 OpenAI 密钥、选目标语言（目前默认译成中文、用 Google）。
4. **历史记录**：翻译历史存本地、可导出。
5. **补充更多翻译引擎**：按需从 Windows 版移植 DeepL、有道、百度等。

> 小提示：免费 Google 接口偶尔会被 Google 反滥用机制限流（返回 [ERROR]）。
> 若遇到，切换到 OpenAI 兼容接口（填入自己的密钥）会更稳定。
